# Rules for doing this

We will mess up a lot so the least we can do is be careful and try to minimize catastrophic mess ups.


As such, we are going to follow the below rules:
- No default arguements. All function arguements need to be passed. 
- All function arguements need to be passed in keyword form. 
- No hardcoded numbers unless they are mathematically unchangeable. Define constants and import them
- Functions Functions and more Functions. 
- Typehinting for everything
